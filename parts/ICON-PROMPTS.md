# Ability icon prompts

One painted icon per move, shown in the round buttons on phones. Generate each at
1:1 (for example 1024 x 1024) and save it as `parts/_icons_full/<name>.png`. The game
uses `parts/icons/<name>.png` (256 x 256); until a file exists the button shows its
line drawing. Keep the subject centred: the game crops to a circle and adds a silver rim.

**rocket.png** (Rocket Pass)
```
Round mobile sports game ability icon, bold painted cartoon style, thick dark outlines, vivid saturated colors, dramatic lighting and glow, one clear subject filling the frame, square 1:1, dark simple background, no text, no numbers, no border or rim (the game adds its own silver rim). Subject: a football blasting forward like a rocket, bright orange fire exhaust and speed lines behind it.
```
